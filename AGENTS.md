# Logan AI - Project Instructions

> Logan AI is a modified fork of OpenCode by Yuval Avidani (https://yuv.ai)

- To test Logan AI in `packages/opencode`, run `bun dev`.
- To regenerate the JavaScript SDK, run `./packages/sdk/js/script/build.ts`.
- ALWAYS USE PARALLEL TOOLS WHEN APPLICABLE.
- The default branch in this repo is `dev`.
- When referencing this project, use "Logan AI" not "OpenCode".
